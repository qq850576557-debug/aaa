# 已确认的鸿蒙目标设备

用户提供：Huawei Pura 70，型号 HBP-AL00，HarmonyOS 6.1.0，软件版本 6.1.0.146 (C00E120R5P5)，API 6.1.1(24)，OpenHarmony 6.1。

仅保留开发需要的型号、系统和 API；未将设备序列号或 IMEI 写入源码、日志或测试资料。

工程产品目标改为 `6.1.1(24)`，不再用 API12 模板代表该设备。API24 满足已查阅原生网络 `maxRedirects:0` 的 API23 门槛，仍要求安装实际对应的官方 SDK 后进行 ArkTS 全工程编译。Hvigor/ohpm 插件版本须由匹配的 DevEco 同步，不能凭设备字符串宣称已经编译。

当前环境只有 Android SDK，没有 DevEco、Harmony API24 SDK、工作室 HAP 签名/profile 或设备连接，`node sdk-preflight.mjs` 明确退出2。没有 HAP 文件、没有此设备原生相册写入验收。

优先验收步骤：

1. 在匹配的 DevEco Studio 安装实际 API24 SDK，打开本工程，检查产品、kit声明、Hvigor/ohpm工具配套并完成编译。
2. 在工作室开发者环境中完成设备登记和签名；证书及私钥只放受控环境，禁止发到聊天或Git。
3. 安装真正的签名 HAP，先验证图库闭环，再做20张真相机连拍。APK可以运行不作为此项验收。
4. 普通第三方未获持续写权限时：完成捕获→等待全部水印任务→一次系统批量创建确认（最多100张）→逐张写入、fsync、读取校验→成功后保留回执、释放私有临时图。
5. 取消保持待保存；明确权限/参数拒绝可修正后重试；创建回执未知时停止自动重建，通过系统选图和字节核对恢复，防止重复图库照片。
6. 验证授权拒绝、过期GPS、横竖屏、20张、空间不足、强退恢复、同一URI重试、系统图库实际可见与像素。

现有 APK 和新 HAP 的私有存储不自动共享。本轮不移走、删除或清空 APK/PWA 里尚未保存的照片；未核实旧照片结果前，不卸载旧 APK 或清除数据。
