# 春茉空间设计｜装修项目管理系统

CHUNMO SPACE DESIGN · 功能与美，共生。

基于 React 19、TypeScript 和 Vite 的可独立使用本地工作台。没有后端或登录依赖，初始数据为空，所有统计均从用户记录实时计算。

## 运行

需要 Node.js 22.12+（本环境使用 24）及 npm。

```sh
npm ci --cache /tmp/chunmo-npm-cache
npm run dev
```

默认端口 5173。生产构建：`npm run build`，本地检查构建产物：`npm run preview`。部署时将 `dist/` 作为静态站点目录，用 HTTPS 提供服务。

```sh
npm test          # 日历、关联风险、备份校验与 IndexedDB 测试
npm run test:e2e  # 真实 Chromium 浏览器交互
```

浏览器测试优先使用 `/usr/bin/chromium`，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。其他环境先运行 `npx playwright install chromium`，Linux 可能需要系统依赖。

## 使用

- 创建项目后自动生成 8 个默认工种；项目支持编辑、复制、归档、恢复和删除。复制会重新映射全部关联 ID。
- 施工计划支持跨月、跨年、同工种多段与重叠任务。左侧固定工种，上下箭头排序；点击名称编辑工种和颜色，含色环、色板、最近颜色、HEX 与恢复默认。
- 日期头或空白日期单击查看当天事项；空白格双击或鼠标拖选创建任务；拖动任务整体移动，拖动左右两端调整起止。单击时间条打开编辑浮窗。新建时可勾选连续创建。
- 手机可横向滚动工期；通过「施工任务」按钮及日期表单完成创建、移动和拉伸的等价操作。日期计算为自然日，包含首尾，不禁止交叉施工。计划及任务合并跨度限制为 3 年，支持 1900—2200 年。
- 所有表单均使用居中浮窗。Escape、关闭按钮或取消关闭，恢复原页面滚动位置与焦点；删除、归档和 JSON 覆盖有二次确认。
- 事项支持分类、负责人、日期、提醒日期、完成状态、搜索和置顶。项目备忘可无日期。提醒是工作台内的计算提醒，**不包含系统推送或关闭网页后的通知**。
- 采购支持待采购、已下单、已到货，可关联施工任务，按「开工前 N 天」动态计算采购截止日期。任务移动后提醒与逾期风险自动更新。未关联时使用指定日期；删除关联任务会冻结当时的计算截止日，保留采购记录。
- 项目总数、进行中、今日待办（事项日期或提醒日为今天，去重）、未来 15 天采购（今天至第 15 天，含端点）、逾期采购和施工统计排除归档项目。逾期是截止日早于今天且未完成；状态标签保留用户选择。

## 数据保存与安全

数据仅保存在**当前浏览器、当前设备、当前网站源（域名、协议及端口）**的 IndexedDB `chunmo-workspace` 中，不会上传 GitHub 或服务器，也不会自动同步。刷新和关闭浏览器后通常保留；隐私模式、清除网站数据、磁盘故障或浏览器驱逐存储会使数据丢失。开发端口和正式域名不是同一个数据空间。请定期下载 JSON 备份并在迁移时恢复。

保存串行执行，显示正在保存、已保存或失败。失败时保留内存数据，支持重试和紧急 JSON 导出；仍有未保存数据时关闭页面会触发浏览器提示。读入失败时禁止写入，避免覆盖无法读取的原数据。

「数据与备份」可下载全量 JSON、校验并覆盖恢复。校验版本、日期、ID 唯一性、字段、项目和工种/任务关联；文件最大 20 MB。不符合格式的文件不会写入。恢复采用单条 IndexedDB 事务替换全量状态。覆盖前请先备份当前记录。JSON 含项目地址、姓名与备注，需自行妥善保管。

## 长图与品牌

PNG 按数据直接绘制完整日期轴、全部工种及任务、事项与项目备注，带品牌标识、项目日期、总工期和颜色图例，不截取可视窗口。长计划每 45 天为一段，统一排在**一张** PNG 中，以免超出浏览器宽度上限。1.5 倍像素输出；超过 5000 万像素或 32000 像素高度时明确报错并保留数据。日期窄格中的超长任务名会省略；完整名称和备注保留在应用与 JSON。单日 PNG 可很窄，任务备注详见 JSON。

`public/brand.svg` 是依据用户提供植物标识绘制的矢量参考稿，**不是上传原始 Logo 文件**。当前会话没有可读取的原图文件，因此未声称已原样使用。可将经过确认的 SVG 原标替换该路径，顶部、图标和 PNG 导出共用该资源；为登录页保留复用入口。

## 代码结构与边界

- `src/lib/model.ts`：类型、Zod 校验、自然日计算、统计与项目复制。
- `src/lib/storage.ts` / `useWorkspace.ts`：IndexedDB 与串行自动保存，独立于 UI。
- `src/components/`：统一浮窗、表单、可交互甘特图。
- `src/lib/export.ts`：数据驱动导出，后续采购/PDF 可复用数据与下载接口。
- `src/App.tsx`：工作台与各模块编排。

第一阶段提供本地单人核心功能及基础采购。账号、权限、服务器、多人协作、实时同步、在线成员、采购清单导出、PDF 和阿里云部署尚未实现；后续可在持久化层引入 API，保留稳定实体 ID。没有无效的协作或登录按钮。
