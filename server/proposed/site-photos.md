# 需创始人审批：工地照片私有存储

不增加数据库表、迁移或付费服务。服务器新增一个绝对路径私有目录，通过环境变量 CHUNMO_PHOTO_DIR 显式启用（未配置时上传API返回503，网页仍可本地保存和下载）。禁止放在public、release或nginx静态目录，建议 /var/lib/chunmo-staging/site-photos，由现有API专用用户独占，目录0700、文件0600。不得默认启用或自动创建生产目录。

按工作空间/拍摄账号/上传UUID隔离，分块暂存（每块512KiB），原图最多50MiB，服务端重新解码方向并生成有身份约束的水印JPEG。单工作空间默认总配额2GiB（包括未完成分块、原图、水印和元数据），文件及中间操作不自动删除。原图50MiB+水印通常1–20MiB，一千张12MP照片估算约5–20GiB，应按实际拍摄量另行批准配额。API只允许同工作空间现有协作权限；上传只允许本人身份、所有下载重新验证登录；无公网静态URL。现有系统没有按工地分配的额外账号ACL，照片遵循现有工作空间共享权限，不声称实现不存在的工地级隔离。

元数据含工地ID和名称、来源时间/定位、账号ID及名称、服务器确认上传时间、文件哈希和尺寸。原图及水印共享上传UUID。定位及设备时间是设备提供的信息，不是考勤证明；相册无EXIF时间时明确标注选图时间。服务端不接受拍摄人覆盖字段。

生产审批事项：目录、专用用户权限、磁盘容量/告警/配额、目录备份和恢复演练、服务器中文字体及内存预算。现有数据库备份不包含该目录，须与元数据、图片整体增量备份到现有自有备份位置；不得向新付费服务上传。恢复时先停用照片写入、恢复整个目录，校验manifest哈希，不回滚工作空间数据库。应用回滚可关闭变量保留目录，照片只读可继续由兼容版本访问。本轮不操作生产、不删除旧数据。

V1边界：当前原图上限50MiB、解码48MP，浏览器水印合成优先保留实际像素，超过24MP或长边8192时按比例降级，若绘制/编码失败再尝试8MP，界面先展示实际输出尺寸，需用户确认。超出安全解码界限时明确拒绝处理，原文件未修改。不支持浏览器无法解码的HEIC时提示使用JPEG/PNG/WebP原图，不伪装成功。

该文件实现按目前单实例Node API设计，工作空间队列锁、分块哈希和原子文件替换保证并发重试。同一目录不能配置多个API写实例；多实例部署前须另行审批共享锁方案。照片UUID和上传者身份只在服务器认证后关联，完成记录不提供修改/删除接口；原图、水印及元数据保留拍摄凭据，另外在现有audit_event表写入一次拍摄审计（不新建表），完成重试不会重复写入。设备时间与GPS不可当作服务器验证的现场证据。上传完成后只清理已验证冗余分块，业务图片与元数据保留。
