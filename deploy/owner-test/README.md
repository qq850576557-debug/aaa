# 业主手机号独立联调站

部署目标为 `https://owner-test.chmsj.cn`，业务源码固定在 `bf028df2d314717c99d52ac6911c969472548135`。Workbench 操作从现有开发分支提取已审核的 `deploy/owner-test` 及复用工具，然后运行 `deploy/owner-test/workbench.sh --install`。脚本内置版本、证书、端口、工具、生产健康和配置冲突校验。

独立测试应用监听 `127.0.0.1:4410`，独立 PostgreSQL 17 实例监听 `127.0.0.1:5441`。只在新实例应用 001–015 和 016 候选 SQL。初始化两个虚构住宅及测试负责人，项目业主授权默认关闭。生产数据库、生产发行目录和员工应用的原设置均沿用原路径。测试站使用同一个获批微信 AppID。程序只在本机读取该 AppID 的现有 AppSecret，写入测试服务的 root 专用配置文件。测试 ZIP 只含公开 AppID、测试地址及业主页面。

追加独立 HTTPS 虚拟主机前，备份正式 Nginx 配置，按实际 Nginx 运行账号验证语法，然后 HUP。正式 API 版本及健康在操作前后对照。测试站验证 HTTPS、API 版本、无令牌访问拒绝、ZIP 完整字节、测试负责人登录和默认权限状态。出现错误时恢复原入口并停止新增测试服务，保留测试库与备份。正式站只在已知 Nginx 上执行平滑重载。日后从生成器更新正式 Nginx 时，可能需要重新合并此临时测试入口。

`--rollback` 可删除本次测试 HTTPS 接入并停止测试单元。仅当现在的 Nginx 配置仍与本次安装快照或原快照一致时执行，防止覆盖后来的变更。测试集群数据和备份继续保留。

看到 PASS 后，按输出路径在 Workbench 查看测试登录账号密码，再访问测试网页。微信后台向现有 request 合法域名列表添加 `https://owner-test.chmsj.cn`，保留正式域名。下载测试站的 ZIP 并在微信开发者工具打开，配置测试负责人生成的邀请路径，用开发者预览验收手机号绑定与撤销。真机手机号验收和采购同步属于后续步骤，测试项目先使用自愿参与测试的手机号。
