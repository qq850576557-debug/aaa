# 春茉工地拍照｜微信原生小程序 V1.0

这是独立微信小程序，不是网站 WebView，不包含采购、项目管理或云端照片库。注册资料尚未齐全时可以先检查源码、WXML/WXSS和本地状态机；真实登录、地点接口、手机预览需要真实 AppID 和负责人批准的测试服务配置。

## Windows 打开

1. 安装微信官方开发者工具稳定版，使用注册小程序的管理员或开发者微信扫码登录。
2. 导入本目录 `miniprogram/chunmo-photo`，编译类型选择“小程序”。不要导入整个仓库，不开启云开发。
3. 已配置你提供的公开 AppID `wxb48a7abb3858a252`，导入时保留此值。小程序正在认证，真机预览和接口权限以微信后台实际开放情况为准；换测试小程序时可执行 `node tools/configure-appid.cjs wx测试AppID`。
4. 基础库选择工具可用的稳定版本，建议不低于 3.7.12；开启 ES6/增强编译。本工程没有 npm 运行时依赖，不需要“构建 npm”。
5. 在小程序后台配置 `https://chmsj.cn` 为 request 合法域名；首次对接必须先在获批的隔离 HTTPS 测试域名验证，修改 `config.js` 的固定 origin 并将该测试域名加入合法域名。不要关闭合法域名校验来冒充上线可用。
6. 服务端专用适配接口未部署前，登录会明确提示尚未启用。代码已准备，但本次不部署阿里云。

AppID 不是秘密；**AppSecret 只能由负责人在服务器安全配置中填写，不能写入本工程、Git 或聊天**。游客模式不能代替真实登录或手机预览验收。

## 使用

员工账号登录 → 选择高德2公里内地点 → 授权相机和相册 → 连续拍照 → 完成 → 三列照片结果。

已授权相册时逐张后台保存，有平台 success 回执并写入本机日志后才记为“相册已保存”。未授权时仍可靠暂存，结果页可授权保存、全选、多选、逐张重试及继续拍摄。失败不删除照片。没有ZIP、分享面板或照片上传。

恢复需登录同一工作空间、同一员工账号。不同账号不能在界面中读取其他账号暂存。会话、密码不写入本地存储；重启后重新登录。网络未恢复时不会删除旧照片。

仅“删除选中”明确确认后删除指定本机副本，不删除系统相册、网页旧照片或其他账号资料。微信卸载/清理小程序数据会影响本地暂存；待保存照片未导出前不要清理。

## 验证命令

仓库根目录：

```bash
npm test --prefix miniprogram/chunmo-photo
node --import tsx --test server/miniprogram-photo.test.ts
```

如需Linux页面编译及官方API声明检查，在独立工具目录安装 `miniprogram-compiler@0.2.3 miniprogram-api-typings@5.3.1`，不要修改原系统依赖，然后运行：

```bash
CHUNMO_WECHAT_TOOLS=/你的隔离工具目录 node scripts/verify-miniprogram.mjs
```

详见仓库 [交付及真机验收说明](../../docs/wechat-photo-v1-delivery.md)。命令行编译、模拟相册回调和 Chromium 像素检查，都不等于微信开发者工具/真实手机通过。
