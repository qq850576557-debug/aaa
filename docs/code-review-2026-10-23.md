## 缺陷、原因与修复

### F01 · P2 · 普通编辑和色环仍阻断整页

`Modal.tsx` 对所有面板调用 `showModal()`，所以“锚定”只改变位置，背景仍变暗、失去交互且锁滚动。已将普通编辑、色环和导出设置改为 `dialog.show()` 的非阻断浮动面板；仅删除、覆盖、放弃修改及顺延决策调用 `showModal()`。补齐外部点击、Escape、焦点返回、触发位置跟随、ResizeObserver 和日历滚动/视口定位。独立色环缩至 420px，保留圆角与阴影。

此改造首轮回归发现拖选 pointerup 打开面板后，同一手势的 click 会触发外部关闭。已按 pointerdown 来源区分真正的外部点击，不采用放宽断言或固定等待来掩盖；原拖选创建测试最终通过。额外实测色环打开、关闭前后 scrollY 均为 1042，浏览位置未被重置。

### F02 · P1 · 合并前序后漏算依赖影响

复现：A 段 10/22—10/25，B 段 10/28—10/29（同逻辑任务），后序依赖 A、10/26 开始；把 B 移至 10/26—10/27 与 A 合并。旧逻辑虽然把依赖改指 B，却只拿 B 原来的 10/29 比较，判定未延长，漏掉 A 的实际结束日从 10/25 延长到 10/27。

修复：保留合并前各前序段的基准，按后序任务原来引用的前序 ID 判断增长；推断关系也纳入被合并段的原日期。确认后一次保存，采购/事项/依赖指向保留段，撤销恢复原记录。新增测试还验证了原本引用 B 的任务不会被错误顺延。

### F03 · P1 · 非法顺延候选阻断合法当前调整

复现：前序在 2200/12/29 结束、后序 12/30—12/31；把前序延至 12/31。旧代码在显示选择前校验 2201 年的顺延方案并直接抛错，合法的仅当前修改无法选择。

修复：当前方案独立校验；顺延候选不可保存时保留原因和预览，禁用该选项，允许仅当前或取消。实际保存并刷新验证：前序到 2200/12/31，后序仍从 12/30 开始；没有保存 2201 年日期。

### F04 · P2 · 导出选项与下载文件状态不一致

复现：生成期间开始日期仍可输入；月度生成后修改范围，旧的下载按钮依旧可点击。

修复：生成中使用 disabled fieldset 锁定全部日期、日历与选项；改日期、清晰度或方式时删除旧结果及错误提示，重新生成后才能下载。新增测试通过可控的 Canvas toBlob 延迟观察真实 busy 状态，并验证下载 PNG 的内容绘制，不只断言下载按钮存在。

### F05 · C · 原始品牌文件不可读取

资源检查仅找到 `public/brand.svg`（第一阶段参考稿）与 `/workspace/attachments/.../Pasted text.txt`（第二阶段需求），没有原始 PNG/SVG。`BRAND_LOGO_SRC` 仍为空。未创建、临摹或生成替代商标。正式品牌验收需要用户提供可读取的原始文件；这一项未标为通过。
