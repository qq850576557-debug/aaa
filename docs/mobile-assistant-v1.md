# 春茉工地助手 V1.0

## 实现范围与共享数据

手机宽度≤700px，或 `/?mobile=1`（PWA启动地址），进入轻量助手。今日/明日、事项、采购、拍照；桌面页面和复杂管理模块保留。首次打开需登录现有云端账号，沿用现有8小时会话，不另设账号或数据库。

| 原有存储/机制                                  | 手机端使用方式                                                   |
| ---------------------------------------------- | ---------------------------------------------------------------- |
| work_record、record_history、record_submission | 原事项API、CAS、精确回执、审计、多人@和本地队列不变              |
| workspace_state采购、purchase tracking         | 原采购编辑器和保存机制，独立于普通事项，不复制数据               |
| 原通知与账号头像                               | 复用 MentionInbox、Avatar、认证会话                              |
| 原IndexedDB事项/工作空间草稿                   | 继续原机制；照片Blob单独本机暂存库，按工作空间+账号+上传UUID隔离 |
| 新照片私有文件目录                             | 原图、水印和拍摄元数据，不加服务端数据库表；生产默认未启用       |

事项提供工地/待完成筛选，完成记录排后并换底色；新建或编辑复用原必填工地、日期及多账号@表单。恢复完成事项时改回“持续跟进”，不再产生旧版“待执行”状态；既有历史状态仍可读，不重写历史。当前工地选择会带入拍照，初次无工地时手动选择，未选前禁用相机和相册入口。没有可信项目坐标，不实现虚构的GPS附近推荐。

## 照片与水印

- 原生 `input[type=file][capture=environment]` 调相机；相册独立入口。真实镜头分辨率由设备/浏览器决定，未宣称能控制最高分辨率。
- 原始文件Blob完整保留。Canvas按EXIF方向解码，以实际像素渲染；JPEG EXIF DateTimeOriginal/时区可读时使用原时间并保留来源。无EXIF的相册文件明确标“选图时间”，相机调用时记录设备时间，均不是上传时间或严格考勤证明。
- 原始 `public/brand/source/chunmo-original.jpg` 直接嵌入，比例保持；共享水印模板含公司“春茉设计”、工地、时间、当前账号、真实GPS/精度或“定位：未获取”。不绘制新Logo、不逆地理编码或编造地址。
- 用户点击一次性定位授权；系统已授权时选图后可获取一次新定位。没有watchPosition、后台追踪或锁屏唤醒。定位失败不阻止保存。
- 设备允许时保留原像素，JPEG质量0.95，不强制1080P。默认安全上限24MP/长边8192；绘制或编码失败再尝试8MP，始终先显示实际输出尺寸供确认，不裁切、不放大。原图50MiB、服务端解码48MP上限；过大、无法解码或内存不足明确提示，原图可直接下载，不伪装成功。HEIC取决于系统解码能力。
- 确认后先把原图+水印+元数据放入IndexedDB事务，申请持久存储；失败保留预览并提供下载。上传不阻塞页面。浏览器/系统仍可能清理网站存储，不承诺退出后后台继续运行；联网上线、回到前台、每分钟或下次启动会检查队列。
- 512KiB分块，UUID+上传者+工作空间、每块SHA256保证重试去重。服务器校验项目存在、重新解码方向、校验不放大不拉伸，并用认证账号名称重新生成水印，拒绝客户端伪造拍摄人。服务器确认manifest完成后才标记云端已保存；上传失败保留本机文件。
- 私有API每次重新认证，禁止公开静态路径；下载校验SHA256；照片完成后复用现有audit_event写入一次拍摄审计，失败不标记云端完成，重试不重复记账。遵循现有工作空间共享权限，同一工作空间协作者可读取已知照片，跨工作空间拒绝。当前系统没有更细的账号工地ACL，不虚称已实现。当前本机列表用于查看、下载和重试；V1不增加跨设备相册浏览模块。

## PWA与缓存

Manifest名称“春茉工地助手”，standalone窗口，原图制作192/512图标及保留安全区的maskable图标。HTTPS部署，iPhone Safari通过分享菜单添加主屏幕，Android Chrome通过安装菜单或支持时的安装按钮。

仅生产构建注册Service Worker。每次构建从index内容生成缓存版本；导航网络优先、静态资源可离线回退，**从不缓存 `/api/`、私有照片、认证或业务响应**。新worker等待用户确认更新，不自动刷新正在编辑的页面；更新后只清理旧的本应用静态缓存，不清理IndexedDB草稿或照片。离线重新启动不绕过原有登录验证。

## 生产启用审批

详见 [私有照片存储方案](../server/proposed/site-photos.md)。不增加SQL迁移，既有14份已审查迁移不变，未连接生产核查记录数量。已有事项/采购/人员/项目数据不合并、不删除、不分类迁移。

**部署前待审批**：私有目录 `/var/lib/chunmo-staging/site-photos`、API专用用户权限、磁盘/配额/告警/备份恢复、中文字体和内存预算。现有数据库备份不自动包含照片目录，需要单独备份整体目录。环境变量 `CHUNMO_PHOTO_DIR` 由负责人审批后配置；未设置时上传明确返回503，本机保存和下载可用。代码不自动创建生产目录、不修改systemd、不自动打开上传，不增加持续付费服务。默认单工作空间2GiB（含暂存），单实例API写入。

## 实际验证与边界

- `npm test`：35文件、189项通过，含EXIF时区、原始字节读取边界、XML转义、禁止身份注入。
- 完整API回归85项通过；另对最终照片代码复测：4000×3000原图字节完全一致、水印4000×3000，800×1200 EXIF方向输出正确，放大拒绝；重复分块/完成只确认一次、空间不足、未启用返回503、跨空间拒绝。
- 手机生产构建Chromium触控模拟（390px、430px）：今日/明日、新增/编辑/完成/删除事项、多账号@、新增采购/状态共享、工地必填；12MP原图与水印、定位拒绝、离线暂存/重连续传、刷新和换账号隔离；Manifest、静态缓存无API、新worker等待确认再切换。
- 电脑1280/1440：13项提醒布局、固定保存状态、人员考核及并发/本地队列回归通过。
- 真实iPhone Safari/安卓Chrome的相机硬件、HEIC、系统安装提示、主屏幕冷启动及系统存储回收仍需设备验收。浏览器测试不等同真机安装通过。手机相机权限与GPS数据不当作考勤证据。

预览仅含隔离测试账号与项目，不是生产数据。未部署阿里云、未操作生产数据库。
