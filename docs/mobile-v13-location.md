# 手机拍照地点选择 V1.3

新拍摄会话取得新鲜WGS84 GPS（沿用90秒、100米精度门槛），转换为GCJ02仅供高德检索，原始GPS不被替换。高德周边搜索使用2公里、不传types、distance排序、每页20条，最多25页。按POI和查询中心的GCJ02坐标计算距离、排除2公里外结果；支持名称搜索、分页、合并去重及按距离排序。最近候选默认选中，可自行选择其它候选；并不证明位于该建筑内。

查询复用已有服务端Web服务Key、启用配置和每日请求安全限额，密钥不下发。搜索350ms防抖，过期请求不覆盖最新列表，会话内缓存最多40页，拍摄不重复查询地点。没有新增付费服务。

GPS有效但高德未配置、超时、配额不足、无结果时保留相机预览，允许手动名称；GPS拒绝或失效则快门不可用。手动名称签名来源为user-manual、nearby=false，水印标明“手动”。POI来源为amap-poi-selected，另外保留POI唯一ID和GCJ02坐标；两类均与原始GPS、精度、定位时间及登录人员分别记录。

地点签名绑定账号和工作空间，上传时校验签名及拍摄时刻的位置有效期，服务端据此确定名称和来源。连续拍摄续期GPS时保留已选名称，不再次搜索POI或重新选择；过期时在前台拍摄会话中尝试更新，失败时禁止新拍摄并允许重试。结束或新建会话清除地点缓存，下次取得新GPS。无后台持续定位。

## 存储和兼容

不修改数据库表，无数据库迁移。新增信息仅保存在新照片现有metadata.json及本地照片元数据中的可选placePoi字段，旧文件/旧签名/待上传队列照常读取。未复制、改写、删除历史照片。原图、水印图、分块上传、幂等请求、账号权限、Safari字节存储、高清输出沿用原实现。

新增鉴权POST /api/site-photos/place用于手动命名及签名续期；原定位接口接受nearby=true执行周边检索，未带此标记的旧客户端继续使用原兼容协议。GPS由浏览器提供，签名不构成独立GPS真实性或建筑内位置证明。

## 验证边界

自动测试使用隔离数据库、Linux Chromium模拟相机和GPS、高德模拟响应。覆盖不限类型混合结果、真实坐标距离排序、2公里边界、分页和搜索参数、无Key手动兜底、过期GPS、签名账号隔离、自由选择及两次连续拍摄不重复检索；运行既有原图、12MP水印、离线重试和PWA事项采购回归。真实高德住宅/农村覆盖、iPhone Safari硬件GPS和安装后的PWA实机效果未验证，需上线后实机验收；未部署生产环境。
