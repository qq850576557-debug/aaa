## 实际原因与实现

### 工种颜色

原实现对已保存的工种颜色再次调用项目色相映射；甘特图与导出因此显示项目色，用户保存的色相看起来没有生效。现统一读取工序记录的 `color`，列表、图例、任务条和 PNG 导出使用同一来源。

- 新项目的八个默认施工阶段使用固定且相邻色相分离的配色；新增自定义阶段优先选择未使用且远离相邻工序色相的颜色。
- 显式修改颜色并保存时，同一工作空间内同名工序同步颜色；新项目继承已有同名工序颜色。编辑普通字段不触发颜色同步。
- 历史已保存颜色直接使用，不在读取时覆盖。历史项目若曾为同名工序分别设置不同颜色，在用户显式保存共享颜色前继续保留各自记录，避免猜测哪个是自定义颜色。
- 快速配色预览仅调整当前工序，完成才同步其他项目；取消恢复原色。砌墙与拆除不会被合并为同一工序。
- 项目颜色仍由原项目主题映射管理，与工序颜色独立。

### 两类数据的关联

- `data.dictionaries` 的 `kind: trade` 是人员技能分类，人员 `tradeIds` 引用字典 ID。
- `data.trades` 是项目内的施工阶段，任务通过 `tradeId` 引用阶段；阶段的 `staffIds` 继续关联原人员。
- 旧人员选项曾直接混入项目阶段名称，并生成候选 ID，造成混用与重复。现在人员候选只来自统一的人员工种目录，已知阶段以及与项目阶段同名的未分类旧条目不再作为新技能选项。
- 复用现有字典，新增可选 JSON 属性 `usage: worker | stage` 用于明确分类；旧记录不要求该属性，读取不自动写库。不增加表、列或 SQL 迁移。发布时前后端须配套更新，旧版严格校验器无法识别新属性。
- 标准工种用稳定 ID，不在每次刷新时生成 UUID；只有实际选择保存或主动管理时才保存相应目录项。
- 统一名称空白与全半角；固定同义词包括泥水工/泥工、木作/木作工/木工、油工/漆工/油漆工等。泥工与瓦工、电工与水电工不会强行合并。
- 同义词分组保留全部旧 ID。改名同步组内名称，已有人员、阶段、任务、类别及历史引用不变。旧阶段关联作为只读“历史关联”显示。
- 已引用工种的删除改为停用；未引用工种保留删除标记。没有物理删除历史条目。

### 页面与排序

- 工种编辑仅展示施工人员及多选列表，项目经理、设计人员、监理控件隐藏，原 `staffIds` 和文字关联仍保留。
- 左侧工种名称、任务天数、师傅信息共用一张淡色圆角卡片；内容整体点击编辑，排序手柄单独处理。手机端师傅摘要单行省略，完整姓名保留在悬停提示与编辑窗口。
- 首页移除四个快捷锚点按钮，实际今日、明日、备忘和施工时间轴保留。
- 人员工种选择器有搜索、已选标签、清除、内部滚动与工种管理。工种管理复用现有字典，支持新增、改名、顺序调整、启停与受保护删除。
- 人员标题后放置紧凑搜索框，继续按姓名、类别与工种搜索。
- 人员排序仅从手柄开始，按真实卡片坐标判断跨行插入点；显示浮动虚影、原位占位与深色插入线。单列手机使用水平插入线，并提供上下移动按钮及 Alt + 方向键。
- 排序保存原有 `people` 数组顺序，不修改人员字段。沿用签名基线、三方合并、CAS、请求收据和账号草稿；顺序与独立资料编辑可合并，相互竞争的排序返回冲突。SSE 在拖动中延迟刷新，取消不保存。
- 人员顺序变动加入现有版本历史，支持原有历史恢复；仅新增或删除人员不会伪造排序变动事件。
- 当前项目使用原项目主色的较深浅色选中背景与明确边框，保留深色文字和悬停差异。

## 人工验收步骤与限制

1. 打开工作空间，确认四个快捷导航消失，实际事项与时间轴仍可新增、编辑和处理；切换两个项目，核对选中背景、边框与文字对比。
2. 点击整张工种信息卡片，确认只显示施工人员选择；原经理、设计与监理关联仍可在其他原有位置查看。只拖手柄时不弹编辑框。
3. 更改工序颜色保存，检查图例、卡片、任务条；刷新、另一账号读取及 PNG 导出核对颜色。确认任务日期与人员关联未变。同名工序共享颜色前请注意跨项目同步说明。
4. 进入人员管理，搜索姓名、类别或工种；打开人员档案查看搜索多选器，确认阶段不作为可选技能、旧阶段关联仍保留。
5. 在工种管理新增、改名、调整顺序；删除已使用工种应提示停用。保存并刷新，核对人员与旧 ID 关联。
6. 拖动人员卡片跨行插入并刷新；拖动中按 Esc 取消；手机用拖动手柄或上下按钮。另一账号应读取相同顺序。
7. 两人同时排序同一目录应保留冲突核对；排序与另一人修改无关记录应各自保存。断网失败时保留草稿，恢复后重试。

自动化使用 Chromium；真实 iPhone Safari、安卓浏览器、操作系统原生拖动手感及超长真实人员名称仍需实机确认。未将有限设备的自动化结果表述为所有设备通过。历史未知自定义名称按保守规则保留；若业务上仍有未识别同义词，应人工确认后改名，不批量猜测清理。原有人员卡片自定义颜色仍是浏览器展示偏好，本轮没有将它改为账号或项目权限数据。
