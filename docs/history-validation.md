## 持久化与恢复设计

保留数据库 `chunmo-workspace`、版本 `1`、原对象仓库 `workspace` 及原 `data` 键。只新增同仓库的 `history` 键，不删除、清库或破坏旧版本数据。首次读取旧项目不伪造旧历史，也不为读操作创建版本。

每次保存从数据库读取前一份已提交数据，与新状态比较；忽略仅更新时间的变化和真正未修改的保存。重要修改产生完整、可验证的项目关联图快照及字段级差异。成功提交的同一个 readwrite 事务写入业务数据与历史；任意一项失败则一起回滚。页面只在事务成功后更新最后保存时间和可恢复历史。普通编辑保存失败时保留当前未保存内容并提示备份、重试；历史恢复失败不会替换当前页面数据。

项目快照包含该项目完整资料、staffIds 人员关联、工种与顺序/颜色、任务及多段/依赖、事项/备忘、采购及原定期限/确认记录。恢复选择记录的 before 快照，而不是逐字段撤销，能够跨越任意多次后续修改恢复到完整旧状态。恢复时保留其他项目当前数据及顺序位置，重新校验整个工作空间的 ID、外键、工期、期限和依赖关系。界面由恢复后的同一份数据重新计算自然日工期、待办、采购倒计时及风险。

全局人员资料、历史姓名候选、项目排序和最近颜色使用独立全局范围，项目面板不会混入全局人员资料。选择“查看完整历史”后可明确切换全局或其他项目，也能找到已删除项目的历史。全局恢复不会覆盖项目内容；若要回到某个已不存在的人员档案之前、而当前项目仍引用该人员，校验会拒绝整笔恢复，不静默清除项目关联。需要先处理相关项目关联或恢复相应人员档案。

恢复前二次确认范围、时间、模块及影响；同一事务中的恢复记录包含完整的恢复前/后状态、来源记录 ID 和时间。恢复到旧版不删除后续记录，可再次恢复其他版本，或恢复到上次“版本恢复”之前。操作者只写“本地操作记录”，没有伪造账号身份或安全审计。

项目名称旁显示本地时区、精确到秒的已成功保存时间。紧凑无整页遮罩面板默认最多8条，提供完整历史、展开前后差异和恢复操作。历史每次保存、启动及每分钟执行保留检查，滚动保留最近15×24小时（含准确边界）；恢复提交时再次校验有效期。超过期限的记录和无引用快照清理；相同完整快照按内容复用，不重复存储连续版本的共同状态。400ms 合并连续色值输入，没有每次鼠标移动或每个输入字符的版本。

有效历史上限10000条、128 MiB。达到上限/配额不足时明确保存失败且保留旧数据和有效历史，不为了宣称保存成功而擅自丢弃15天内版本。清理旧版本失败独立处理，不修改当前业务图。建议定期下载备份。历史是有界的本地恢复能力，不是无限云备份。

保存和历史恢复都有数据库中的已提交基线比对；发现另一标签页先保存时拒绝覆盖，并提示备份未保存内容、重新读取。没有实时协作、合并或自动替别人覆盖数据的假象。

## 备份与兼容

原“下载完整 JSON 备份”继续导出兼容的完整业务数据（含人员档案及关联），新增“下载业务与版本备份”使用 `chunmo-history-backup` 封装，同时保存业务数据和完整15天版本图。恢复器同时接受旧纯业务 JSON 和新封装；先校验全部内容并二次确认，保存时合并有效历史，不删除已有后续历史。同 ID 不同内容的版本/快照会报错，不能静默覆盖。导入大小上限140 MiB。JSON 恢复也有恢复类型及来源记录。

保持数据模型 v1，新 `people` 与项目/工种/任务 `staffIds` 均为可选，旧姓名文本和原采购字段保留。项目状态继续接受旧“筹备中/进行中”，界面统一施工中，完工项目保持独立入口。没有凭姓名重建已有对象或擅自转换旧记录。

## 界面与人员流程

- 人员管理支持姓名、类别、工种、备注的新增、编辑、停用/启用、保护性删除以及分配到具体项目/工种/任务。删除采用保留 ID 和原关联的删除标记，不级联删除项目；全局历史可恢复。
- 旧姓名登记和候选保留在人员模块，可按原姓名建档。人员只在此维护资料，任务编辑通过注册人员下拉框保存 ID，项目/工种表单不重复登记详细人员。已停用人员不能新增分配，已有引用仍保留。
- 项目名称下方删除重复人员登记条和地址占位；设计团队与监理只从实际关联读取，没有人员就不虚构。项目计划日期和总自然日工期保留。
- 新建项目限工作空间/完工项目；施工长图导出移入施工时间轴；人员页只保留相关人员操作，采购在选定项目下操作。重复完工切换按钮移除，左侧完工入口和标记/恢复功能保留。
- 双击空白日期进入三字段采购表单，自动继承项目及日期，不创建施工 Task；施工任务仍通过明确“施工任务”入口或拖选创建。已有时间条双击不编辑，拖动、两端拉伸、右键确认删除、分段合并和顺延确认保留。
- 单轨工种行由56px压至34px（约39%），时间条26px、任务文字14px；重叠任务仍增加轨道。工种名/任务天、排序箭头清晰，移除更多菜单和重复编辑按钮；拖放60%透明、红色释放线、行间加号、实时颜色保留。
- 工种编辑约510px、最多视口75%，色环104px；独立色环100px，保留常用、最近、饱和度/明度、自定义及恢复默认。实际页面检查发现并修复紧凑行文字溢出和历史面板高度约束的 CSS 优先级问题。
- 项目内采购仅内容、截止日期和备注，显示只读所属项目，不重复下拉选择。所有列表仍引用同一 Purchase，当前日期文案改为“今天截止 / 剩余 X 天 / 已逾期 X 天”。原始期限及独立确认流程保留。
- 成功和失败的浮动提示均在顶部约3秒消失；需要处理的持久化失败和导出失败原因另有稳定的行内错误与重试入口，不依赖已消失的浮动提示。
