## 1. 小程序候选及提审

- 使用 `deploy/owner-release/package.py --owner-sha <完整提交> --employee workbench --output <ZIP>` 生成内部审阅包。需要拍照版基线时选择 `--employee photo`。打包保留员工默认入口、账号密码、定位、相机、相册、照片队列及对应基线的工作台路由。员工登录页给出业主入口，业主页的员工按钮打开原员工登录页。
- 缺少正式协议时，候选包的业主手机号登录保持关闭。创始人确认协议后，用 UTF-8 JSON 文件提供 `version` 和 `text`，通过 `--terms` 参数生成待提审包。隐私指引由入口直接打开微信后台登记的指引。正式包与测试包分开存储业主会话。
- 负责人在项目授权后复制一次性口令，通过已核对的私下渠道交给该业主。业主在同一小程序进入「业主微信登录」并粘贴口令。有效期 24 小时，服务端核对手机号、预授权、项目与现有微信绑定。首次绑定完成后续用会话，跨项目授权各自记录。
- 线上员工版本已按截图记录。提审前在微信后台核对正式 request 域名、手机号能力及额度、备案与服务类目、隐私指引和审核要求。需要审核人员登录时使用平台认可的专用非生产验收方式，先由负责人批准测试入口和资料范围。
- 审核前用同一待提审包核对员工登录、定位、拍照、水印、系统相册及对应工作台功能。微信公开发布前记录线上旧版、待发布版、微信审核结果和回退所需管理权限。

## 3. 单住宅试点审批

请负责人另行确认**准确项目、参与业主、开放时段和验收人**。试点项目之外的住宅保持默认关闭。按网页授权、微信手机号首绑、打开清单、下单并填写品牌型号、公司确认到货、手机刷新核对、撤回发布与撤销授权复验执行。并行复验原员工登录、拍照、定位、水印和相册。验收记录只写测试结果，手机号和邀请口令不进入报告。

待分别审批的事项为**生产迁移及部署版本、微信公开发布、单住宅试点范围及实际费用**。本次交付到候选构建、预检准备和隔离验证。
