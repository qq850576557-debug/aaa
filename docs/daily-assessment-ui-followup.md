# 每日考核、人员关联与保存反馈：交付记录

本轮沿用 daily_assessment、assessment_history、assessment_submission、原工作空间人员档案和原持久待同步队列。没有新增SQL迁移、没有连接生产数据库、没有部署。

## 数据兼容与更正

- 考核记录追加可选 withdrawn/correctionReason。移除只撤回指定工地、指定人员、指定日期的原来源记录，原状态不清零，真实操作人员和服务器时间继续进入不可变历史；统计排除撤回记录。
- 重新选人先撤回原人员本日来源，新人员从未记录开始，不复制成绩。重新选回撤回人员时恢复其自身来源，所有恢复动作继续保留历史。其他日期/工地完全不受影响。
- 更正通过原持久队列、原回执、版本CAS和事务保存；网络未确认保留原请求，409必须核对最新来源，替代请求成功后才移除旧失败回执。
- 人员档案追加可选 identityLink（主档案ID、人工确认原因）及 hiddenFromSelectors。只建立可撤销的兼容映射，不改写旧人员ID、工地/任务分配及考核原始来源。
- 按确认映射归并视图，同一工地同一天只计一个人日；yes/no冲突保留来源、标为待核对，不重复计天、不算失败。写回时仍使用每个来源自己的原始ID与版本。服务端防止继续新建同一主档案的重复人日。关联缺失或循环会被数据校验拒绝。
- 新增时同名同工种只触发候选提示，可确认关联、确认不同人员或取消。关联历史已移出档案时，新档案作有效主档案，旧档案保留并关联；关联现有有效档案时沿用该主档案。全部沿用工作空间历史及多人保存保护。

## 界面与保存

420px范围的工地卡片紧凑排列；数据小结浮层不占预留栏位。每个工地独立选择北京时间日期，未来日期禁用。图标三态直接操作，空白和未选项弱化；姓名有更正、移除与独立历史入口。

确认响应更新现有行；后台刷新不加入/移除loading文本，状态说明保留固定位置，防止保存造成页面跳动。没有全页刷新、改变卡片key或重置其他工地日期。统计只使用服务器确认数据。

左下角固定保存反馈，取服务器生成的真实记录updatedAt或工作空间历史at；精确到北京时间分钟。无内容变化或重放原回执不生成新的业务保存时间。只在确认响应之后更新，按账号隔离缓存；本地待同步、上传和失败明确区分。严重错误原警告及待同步备份保留。首页今日/明日内容与状态放在统一浅绿背景，已下单用暖色，按钮/标签使用全局留白变量。

## 生产人员核查与待审批清单

生产未核查，不能从截图或姓名确认真实身份，因此没有执行任何生产人员合并/停用/删除。

| 候选                   | 当前证据与处理                                                      | 仍需核实                                                         |
| ---------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 叶发华等同名同工种多ID | 提供待核对候选、原档案→主档案选择及可撤销关联；隔离测试验证归并统计 | 每个真实ID、备注、分配、原始考核数量、同日状态冲突、实际本人身份 |
| 阿萨德官方             | 提供明确确认停用/隐藏候选操作，保留所有历史                         | 生产实际ID及其关联确实为测试用途；未擅自操作                     |
| 其他历史/移出档案      | 不以同名自动合并，继续保留原记录                                    | 逐人身份及主档案归属                                             |

如后续需要生产物理改ID、永久删除或批量合并：先导出逐ID影响清单（档案、分配、任务、考核、人日重复组、历史事件及待同步内容），生成可验证恢复的加密一致性备份，记录原ID→主ID映射与发布版本，在独立库验证恢复/回滚，再取得创始人对具体范围的批准。当前兼容展示不等于此类批准。

回滚优先撤销identityLink（原数据未改）。已撤回打卡可通过重新选择原人恢复，并记录新历史。代码回退应保留新可选字段，不能用旧客户端全量备份覆盖新增的映射/撤回状态。
