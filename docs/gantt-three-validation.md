# 甘特图三项优化验收

范围：当前 `feat/chunmo-project-manager` 增量修复，不改数据库结构、账号权限或部署配置，不连接生产环境。

## 实现

1. DateField增加可选隐藏可见标签，仍保留无障碍名称。时间轴工具栏使用同高、居中、可整项换行的控件，桌面同行，窄屏自动换行。日期定位、今天、导出和新建任务入口不变。
2. `ganttGroups`按项目和工种对日期区间作传递合并（重叠或相邻自然日），仅产生显示投影；不按名称猜测、不删除记录或重写引用。工种天数按区间并集计算，PNG复用同一投影。独立空档仍分段显示。
3. 合并框整体拖动对所有成员应用同一天数差；边界缩放只扩展边界成员、缩短时将成员限制在新框范围，完全被缩出范围的成员保留为边界当天的一日记录。ID、备注、状态、人员、依赖、采购和事项引用继续保留。通过原有保存/版本检查流程一次提交，可撤销、恢复历史。原始任务详情列表仍全部可用；合并框右键可明确选择原始记录后编辑或确认删除。
4. 日期编辑和拖动复用同一排期预览。结束日期提前时，显式依赖链优先；无依赖的任务仅考虑本项目工种顺序在后且原先在当前工序结束之后开始的未完成任务。原先独立交叉施工、已完成任务、其他项目、当前工序的前序不提前。后续任务统一平移结束日期差值，保持持续天数和相互间隔；不得越过未调整的其他前序。联动范围超出合法日期时禁用同步，仍可仅改当前。
5. 提前显示“当前工序已提前，是否同步提前后续工序？”，选择“同步提前”或“不调整”；关闭/取消不保存。一次指针释放后产生一次预览，原有过期预览检查、触屏去重和后延顺延流程保留。保存后所有投影读取同一原始任务源。

## 修改文件

- `src/components/Gantt.tsx`、`DateField.tsx`、`ScheduleConfirm.tsx`、`TaskContextMenu.tsx`：工具栏、显示分组与批量拖动、提前确认、原始记录选择。
- `src/lib/gantt-groups.ts`：显示投影及组内日期映射；`src/lib/scheduling.ts`：批量预览和提前联动；`src/lib/export.ts`：同源区间导出。
- `src/App.tsx`：接入一次性批量保存；`src/style.css`：仅时间轴工具栏对齐规则。
- `src/lib/gantt-groups.test.ts`、`tests/gantt-three.spec.ts`：新增区间、跨年、缩放、联动、隔离及桌面/手机交互测试。
- `tests/stage2.spec.ts`、`tests/review.spec.ts`：将旧的物理合并删除断言更新为显示合并、记录与引用保留，继续检查后延顺延和撤销；`tests/stage4.spec.ts`：采购提前拖动显式选择“不调整”，保留采购截止日期及统计断言。
