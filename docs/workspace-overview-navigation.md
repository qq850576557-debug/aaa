# 工作空间总览与单工地导航

## 页面与范围

无工地参数的首页、品牌入口及左侧“项目工作空间”均进入全部工地总览，左侧工地不选中，不挂载单工地甘特图。标题下显示五张约74px高的统计卡，保留真实名称和数字。

点击任意左侧工地的选择区域，以唯一项目ID进入其工作空间，保留既有选中配色、今日/明日提醒、施工时间轴及项目操作。统计改为标题旁紧凑标签，并将同一统计函数限定到该工地。其它业务页面的菜单入口清除工地选中状态，左侧项目仍可直接进入对应工作空间。

总览提醒复用原事项、采购、历史来源和日期规则，归一化为“施工中”的未归档工地参与汇总；兼容原“进行中”“筹备中”状态，已完工、已归档和暂停项目不混入总览提醒。单工地入口保留该工地的原有记录读取规则。五项统计沿用原统计函数和待办计数口径，不取提醒预览的卡片数代替统计值。

保留原完成状态、采购四态、历史置顶优先级、日期排序、已完成弱化/后排及提醒操作。记录只形成页面投影，没有复制、合并、重分类、迁移或删除。总览新增事项不预选第一家工地，沿用原表单要求选择工地后保存。

首页业务日期使用Asia/Shanghai，同一日期传入单工地时间轴的“今天”显示；拖动、调整工期、排序、配色、保存及并发校验逻辑不变。侧栏上方的“工作空间 / WORKSPACE”装饰字已移除，品牌源文件未变更。

## 导航与草稿

- 单工地链接：`/?project=<项目唯一ID>`。
- 业务页面链接：`/?view=records`、`/?view=purchases`等。
- 当前统计筛选可随路由保留；不使用工地名称匹配，也不写入业务数据库。
- 刷新及直接打开链接可恢复该工地。无效项目ID返回总览，不选择第一家工地。
- 前进/后退恢复页面、项目选择及浏览位置。普通导航不整页刷新；保存确认不改变路由或滚动。
- 沿用记录编辑器的本地草稿及离开确认；取消后保留编辑内容与当前地址，确认后按原流程归档草稿再导航。其它已打开的编辑窗口要求先保存或关闭，浏览器导航被拦截时恢复原地址。

## 验证

- 215项单元测试通过。
- 16项电脑浏览器回归通过，包括1280/1440两种布局、同名工地按ID跳转、五个主要页面跳转、直接链接/刷新/无效ID、前进后退、滚动恢复、草稿拦截、总览新增/编辑/完成、统计与提醒保存联动，以及原有断网恢复/并发保护。
- 使用洛杉矶浏览器时区和跨北京时间午夜的测试时刻，验证今日/明日和时间轴“今天”采用工作室日期。
- 导航测试前后比较工作空间与事项API记录，确认纯导航不产生业务写入；测试资料为隔离环境的合成资料，未采用需求示例作为真实数据。
- 3项甘特图回归通过，覆盖桌面滚动、拖动、调整日期、新增和项目样式。
- 12项手机PWA回归通过，覆盖事项/采购、照片、水印、连续拍摄、断网重试及本地照片保留。未新增手机功能，未删除待上传照片。
- TypeScript、生产构建、部署工具构建及diff检查通过。
