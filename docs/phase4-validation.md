## 代码核查发现

1. 今日事项只使用 `notes`；未来采购及统计使用 `purchases`，没有把今日到期的采购投影到今日事项。新增入口还会创建独立 Note，无法共同更新完成状态。
2. 甘特日期表头把整个项目的采购都当作每一天的采购提示，未按有效截止日过滤。
3. 旧关联采购直接以任务开始减提前量计算，施工推后会静默延后采购；没有原定期限上限。
4. 每日事项表单确实误带持续天数、前序、关联任务和单独提醒字段。
5. 时间条单击/双击定时器都会进入任务编辑；没有右键删除入口。
6. 项目状态与过滤只判断“进行中”，新建默认“筹备中”；不存在独立人员管理导航。

## 实现与数据关系

### 一份采购记录，多个视图

新增每日采购及未来采购入口统一调用采购表单，保存同一个 `Purchase`，不另外创建 Note 或 Task。表单只有采购内容/事项标题、所属项目、采购截止日期、可选备注四个输入；默认当前项目，已有采购不能通过普通编辑迁移项目。状态在卡片处理，不放入每日录入表单。

`procurementView`、`purchaseDue`、`purchaseComplete` 和 `remainingTime` 提供统一投影与日期判断。今日、未来 15 天、采购管理、事项页、提醒中心和日期轴都由原记录派生；同一 ID 在两个区域展示不产生第二份持久化数据。状态、日期或内容保存后立即同步各处。

- 今日显示当前项目今日及逾期未完成采购；保留旧事项。
- 未来窗口为今天至第 15 天，含端点，超出第 15 天不显示。
- 已完成和旧已到货均排除待办/采购提醒；已下单仍待完成。
- 全局统计只汇总未完工/未归档项目；项目切换严格按 projectId 过滤。
- 相对时间根据自然日计算，不存手工剩余天数字段；跨月、跨年、闰日使用原日期工具。每 30 秒、窗口聚焦或重新可见时更新当前日期，跨午夜不要求编辑记录。
- 日期轴标记按当天的采购截止计算，点击日期可看到同一条采购。采购截止早于施工轴起点时仍在今日/逾期列表显示，不擅自扩大施工计划日期。

### 原始期限保护

新增可选字段，格式仍为 v1：

| 字段            | 作用                                                   |
| --------------- | ------------------------------------------------------ |
| originalDue     | 最初保存的采购期限约束，普通编辑和明确变更均不替换     |
| deadlineMode    | fixed 为固定采购日期，linked 为保留旧任务联动计算      |
| approvedDue     | 经独立明确确认后的当前期限上限，无确认记录不得单独出现 |
| deadlineHistory | 保留每次明确变更的 from、to、原因和时间，校验链条连续  |

普通保存通过 `savePurchase` 对照已有记录校验；不能靠修改表单中的原始日期或确认字段绕过上限。允许提前，也允许在原定/已确认上限内调整；超出则报错且不写入。日历禁用超上限日期，手动输入仍经过业务校验。

确需调整上限时，打开独立“变更原定期限”确认窗，要求新日期、非空原因及明确提交。保留最初 originalDue，追加历史并调整 approvedDue。窗口明确说明这是本地确认，**不是负责人账号授权、服务端权限或不可篡改的操作审计**。没有伪造身份角色。

旧采购在读取后仅于内存补齐当时有效期限，下一次实际修改才持久化；不在读取时改写数据库。旧版本没有记录的最初创建期限无法追溯，不假装能恢复。原 due、数量、规格、负责人、记录 ID 和关联保持可读。JSON 完整保存新约束与原因，拒绝不完整或不连续的变更链。

旧关联采购随施工提前而提前，推后时受期限上限限制，不自动延期。用户手动设置采购日期后采用固定计划并保留原任务查询引用。采购日期修改不创建 Task、不改变施工自然日长度，也不进入施工顺延逻辑。删除任务时冻结有效采购截止并解除任务关联，采购内容与历史不丢失；分段合并仍重映射引用，原期限保护保留。

### 工期与导航

- 双击已有条不打开任务编辑，单击也不进入详情；整体拖动和两端拉伸保留。
- 右键打开页面内 190px 轻量菜单，含编辑任务详情和删除时间条；无全屏遮罩。删除单独确认，可取消。Enter/Shift+F10 可访问操作；下方“任务详情与多段管理”提供独立鼠标/手机入口。
- 删除时间条后清理前序依赖和事项任务引用，保留事项内容、采购与人员历史。其他时间条不受删除影响。
- 项目新建默认施工中；旧筹备中/进行中仍被 schema 接受，页面、卡片、筛选、统计和 PNG 用统一显示映射。读取不改原状态，项目编辑保存或恢复完工项目时采用施工中。施工任务自己的“进行中”状态保留。
- 人员管理新增独立主导航和现有登记汇总，明确员工档案、工种归属及分配的后续职责。未新增员工资料表或手机号、生日输入；未声称真实权限已实现。原项目、工种、任务人员登记保留，采购表单不登记人员。
