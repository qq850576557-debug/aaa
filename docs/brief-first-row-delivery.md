# 电脑首页提醒：收起保留第一排

本轮基线 b78bf64c4c1395dbb1596595c579f2fdcf712be5。仅修改桌面工作空间的今日事项/明日提醒；每日必做的收起行为不变。

## 实现

- 两个 BriefPanel 显式启用 collapseToFirstRow，移除旧的无效固定数量 previewLimit 参数。
- 默认全部展开。收起时在 layout effect 中按真实卡片的布局位置识别第一排，仅给后续整张卡片设置 hidden。没有固定卡片数量，没有固定高度裁切，也没有复制/重排事项数据或替换原点击处理。
- ResizeObserver 监测容器宽度，窗口 resize 合并到 requestAnimationFrame 重新测量；高度变化不触发观察循环。展开、内容变化和卸载时恢复隐藏节点。
- 收起的卡片区域、内容网格和父面板按自然内容高度布局；任一面板收起后不再被另一面板强制拉伸。保留日期、总数、底部原有新增/全部事项入口、工地主题色及状态标签。
- 继续使用原来的每个面板独立运行内存状态：菜单返回保持，刷新/新打开页面默认展开。未写 localStorage、IndexedDB、接口或数据库。
- CSS 仅作用于桌面 agenda-brief 中显式启用的面板；没有修改小程序、手机网页或任何其他客户端。
