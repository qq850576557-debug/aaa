## 加载瓶颈与实测

修改前生产包将非首页业务一并下载，首屏 JS gzip 为约 206.4KB。登录门禁先请求 `/auth/session`，工作空间挂载后再次串行请求相同会话，然后才读取数据。`/purchase-records` 全量摘要随 `data.purchases` 和保存状态变化反复读取，属于本轮移除界面入口后不再需要的请求。

现在首屏 JS gzip 约 175.6KB，材料、人员、事项代码到进入对应页面时加载。首次打开仍读取服务端最新 `/workspace`，不使用业务快照缓存；生产构建十次测量均只有一次会话请求和一次工作空间读取，没有采购审计摘要及非首页模块的请求。在线人员不阻塞首屏。

同一 Chromium、相同数据（1 工地、3 施工任务、12 采购记录）、相同 API/数据库、生产构建、每种条件五个新浏览器上下文；已登录会话，禁用浏览器 HTTP 缓存。从导航开始计时，直到已保存状态、任务条渲染完成，云端和草稿检查均已完成。密码散列登录耗时不包含在此工作空间重开测试中。

## 安全与兼容性

- CAS、签名 baseProof、三方字段合并、幂等回执、服务端身份与权限、SSE、409 冲突处理及数据库事务均保留。
- 刚验证的身份只在当前挂载使用；所有 API 仍重新验证会话，登录失效、焦点/定时复核及跨账号隔离保持不变。
- 草稿必须按账号/工作室/标签页读取完成后才开放编辑；不让缓存快照覆盖云端，不清除 IndexedDB 或浏览器站点数据。
- 没有新增迁移，原迁移与旧数据兼容性由现有隔离迁移回归检查，生产未执行迁移。
