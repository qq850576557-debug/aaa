# 桌面卡片与负责人入口优化

日期：2026-11-02（北京时间）。基线：`74b0d9d8c0bb8306d15a733075289e303263977e`。分支：`feat/chunmo-project-manager`。

## 实现范围

- 首页今日/明日卡片固定为128px小方框，标题最多两行，工地省略，日期与真实状态保持显示；点击正文打开原完整详情。内容不撑高卡片，展开后仍限制容器高度。保留原状态操作及保存保护。
- 事项看板、采购清单的完成记录采用柔和绿色背景、边框和侧边标记。显示时先未完成、后已完成，各组原日期排序继续作为次级顺序。仅排序筛选得到的数组，不写回原数组顺序，不改日期、负责人或项目归属。
- 桌面采购卡片由220px缩至180px（面积减少约33%），首排依次为状态、编辑、删除；等宽等高，删除重复完成按钮。工地标签移到卡片最后；中间正文独立滚动，长内容可通过原编辑入口完整查看。
- 当前工地筛选使用独立的中度绿色背景。
- 事项负责人采用一个复合输入框：保留自由文本，输入@查询账号，多账号显示可单独移除的标签；支持鼠标和Enter选择、Escape关闭，中文输入法组合期间不会误触选择。采购编辑原@入口保持原行为。

## 数据映射与安全

本次无迁移、无数据库结构变化、无数据清理；现有 `owner` 自由文本及 `mentionIds` 账号ID继续分别保存，仅共用编辑入口。未把历史姓名自动转成账号，也不改原通知对象。尚未选中账号的@文本保留为普通负责人文本，只有明确选择账号才增加通知关联。编辑旧记录时已关联的停用/未知账号仍保留，继续交给原服务端权限和有效性校验处理。

沿用前轮 IndexedDB 日志、增量请求、稳定请求ID、幂等回执、冲突检查、事务、审计、历史和SSE；本轮没有改变同步协议及服务器保存逻辑。原性能报告位于 `docs/performance/save/README.md`，其测量值属于前轮实测，本轮不将其冒充为新测量。

所有交互测试使用本地隔离合成数据。没有访问、迁移或修改阿里云生产库，生产数据数量与内容未单独核查；未开发手机APP或新的手机页面。
