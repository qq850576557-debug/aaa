## 实际实现

### 采购、菜单、标题与项目色

- 采购管理采用同尺寸网格卡片，显示名称、工地、截止日期、倒计时、状态、原负责人和服务端可信责任时间。完成、编辑、删除及历史仍调用原处理逻辑；缺少旧历史时继续显示未知，不编造创建人或时间。
- “记录状态看板”统一改为“事项管理”，沿用原视图、API和数据。原日常记录仍在同一页面内保留，无自动转库或新建模块。
- 菜单使用浅绿背景及明确的悬停、按下和选中态；140ms轻反馈，支持减少动态效果偏好。
- 同数据、1440px窗口真实测量：左侧项目卡片高度从166.1875px到133.1875px，缩小19.86%；宽度189px不变。文字字号、状态、剩余工期、预计工期、日期和设置按钮保留。手机设置按钮保持38px触控尺寸。
- 页面标题和说明采用共享排版，空间不足时换行。
- 统一项目主色由共享主题层分配，项目卡片、工地框、事项列/标签、采购卡片、工种图例和时间条复用同一色相。时间条与PNG导出共用同一个颜色投影函数，原工种颜色与全部任务数据不重写；调整深浅仍同步页面与导出。红色逾期、错误等业务风险提示继续保留其语义。

**项目配色范围：** 当前为按工作空间隔离的浏览器外观配置，记录在`chunmo-project-hues:<workspaceId>`（本地模式为`local`）。按项目ID稳定保存；切页、筛选、刷新、排序及新增/移除其他项目不会重分配已保存主色。新项目尽量选择未使用、且与相邻项目有区分的颜色。颜色是视觉归属提示，不作为项目身份或风险判断依据。

这不是云端共享字段；没有增加数据库迁移。不同设备在不同时间首次加载、项目集合或顺序已经变化时，可能得到不同的外观分配。跨设备共享自定义项目配色尚未实现，不能称为已同步到云端。

### 无框竖版个人名片

- 顶部头像和姓名均可打开个人名片；头像、姓名及英文名、职位、部门、入职日期和原品牌Logo均保留。
- 使用紧凑竖版、上图下文、现代中文/英文字体栈；中文姓名30px、英文名22px，深绿与中性色。没有引入外部字体、替换或重绘品牌Logo。
- 去掉内部边框和重阴影；关闭和账号设置轻量浮在照片区域，部门管理仅按原负责人权限显示。
- 名片以原生对话框居中显示，遮罩暗化及7px Backdrop Blur仅作用于背后页面。淡入/轻上浮与150ms关闭过渡尊重减少动态效果偏好。遮罩、Esc和关闭按钮有效。
- 点击照片打开独立大图，清晰展示保存图片的真实比例/尺寸；更换照片使用独立按钮，不再与预览冲突。加载占位、失败提示及重试均有实际验证。
- 修正共享弹窗对“原生模态框内的现有编辑窗”的判断，并阻止子对话框cancel事件向父层传递。Esc先关闭上层预览/编辑，名片继续保留；现有确认框行为保留。

### 图片清晰度及最小服务端兼容

旧上传曾强制裁切为256×256，丢失的原图细节无法恢复。现有图片不自动替换；不足分辨率明确提示。

新名片照片保留比例、不主动放大小图，长边最多1024px；仍要求原文件小于2MB且像素数不超过原16MP限制。PNG处理结果超限时逐步缩小，未放松2MB编码文件限制。显示使用`object-fit: contain`，大图不强制放大超过保存分辨率。

服务端仅为原`card-avatar`接口复用PNG校验时传入1024px上限；系统头像默认仍为256px。继续在解码前限制尺寸、拒绝交错/非法格式、验证CRC、重编码去除元数据。认证、本人写入、工作空间读取隔离、审计和权限逻辑未修改；仍使用原bytea列，无数据库变更。

## 时间轴实现方式

- 在既有`.gantt-scroll`上注册唯一的原生`wheel`监听，`passive:false`，组件换项目/卸载时移除并取消待执行帧。
- 只处理日期网格、日期表头和月份网格。工种固定栏、任务条、输入框、下拉框、可编辑内容和独立滚动区域不强制转换；Ctrl/Meta缩放、Shift原生横滚也保留。
- 像素/行/页单位先转换为像素；斜向触控板取主方向，避免把两轴相加。单次增量限制在280px或当前宽度80%以内。requestAnimationFrame合并同帧增量，保留小于1px的余量，避免细微触控板输入停滞。
- 处理网格内事件时才preventDefault，同次操作不会同时推动网页上下滚动。网格外恢复浏览器原行为。
- 只改横向scrollLeft，继续由原onScroll更新虚拟日期窗口；CELL仍为56px，不提交任务数据。现有拖动仍按鼠标距离加滚动差计算日期。
- 删除拉伸热区的点状伪元素，主体保持移动；只在左右热区悬停/拉伸时显示半透明边缘、虚影和ew-resize。保留原移动、合并、拉伸、新增、右键、工序联动、确认与保存流程。
