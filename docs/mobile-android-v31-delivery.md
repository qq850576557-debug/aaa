# 安卓拍照保存兼容与性能优化 V3.1

用户报告华为手机浏览器、vivo手机浏览器可拍摄但无法保存。未提供具体型号、系统及浏览器版本，本轮没有连接这些品牌实机。下面的兼容结论来自能力模拟和本地浏览器测试，不能替代现场验证。

## 保存流程与故障处理

代码检查发现：原来完成拍摄后等待异步准备文件再分享，可能失去浏览器要求的用户激活；不支持多文件分享时缺少完整ZIP出口；部分浏览器分享Promise不返回会让操作长期锁定。无法仅据此认定两款实机的唯一故障原因。

- 完成拍摄只结束摄像头会话，显示处理进度。文件准备完成后显示「保存N张照片」，在这次真实点击中直接调用系统分享，不在分享调用前等待图片生成。
- 检查文件名称、JPEG MIME及非空大小，检测多文件分享能力。取消、权限/手势拒绝、数据限制及参数不兼容分别显示原因，不冒充相册保存成功。
- 系统分享超过12秒不返回时显示明确提示，ZIP仍可使用。避免同时重复调用原生分享；用户关闭原系统面板后可继续处理。
- 不支持分享或分享失败时自动准备完整ZIP，之后点击下载链接。显示实际ZIP文件名与张数，明确下载/文件目录不等于系统相册。无批量下载循环，无顶层Blob导航。
- 备用入口含单张分享、逐张长按保存、最多5张分批分享及分批ZIP。ZIP优先流式写入OPFS，兼容路径内存预算64MiB；分批优先限制5张/约16MiB，超大的单张需改用支持相应能力的浏览器。超过ZIP32限制时拒绝打包并保留源文件。
- ZIP使用标准STORE格式，逐张读取、分块CRC，JPEG不额外重编码。缓存已准备的同批ZIP，打包前释放大批量分享File缓存，只保留一张以支持单张分享。
- 分享成功返回、下载请求发出和图片展示均不代表系统相册已经写入。只有用户明确点击「已确认导出，清理副本」后才清理对应临时照片及关联导出ZIP。失败、取消、关闭页面均不主动清理源照片。

## 连拍与测量

- 相机会话内保持视频流，优先ImageCapture实际静态拍照；不支持时使用视频实际像素捕获。未强制缩小分辨率或低清放大。
- 在地址选择期间预热捕获Worker；支持时将视频帧JPEG编码移至OffscreenCanvas Worker。不支持或失败时使用完整像素Canvas兼容路径，记录实际采用的编码器。相机结束后释放闲置编码线程。
- 保留原有独立水印Worker、Logo预加载、定位会话复用、串行水印队列及背压。实时水印时钟移到独立memo组件，避免整页每秒重渲染。
- 新增/保留首帧、相机初始化、硬件静态捕获、帧捕获编码、水印编码、本地写入、文件准备及分享调用测量。分享返回耗时包含用户操作时间，不能作为系统菜单出现耗时。
- 连拍输出及时写入IndexedDB；不把所有原图、位图及Base64长期留在内存。单张恢复导出才生成展示数据。浏览器强制清理站点存储仍可能影响本地文件，不承诺永久保存。

本轮模拟10/20张连续拍摄的实际像素、分阶段中位/p95及长任务观测见[性能记录](mobile-android-v31-performance.json)。Linux Chromium使用模拟摄像头、GPS、POI和分享桩；没有真实安卓或iPhone前后对照数据，不声称已测得实机提速。视频帧输出3840×2160，另有4000×3000静态水印回归；这不是设备最高镜头分辨率承诺。

不并行运行单元测试时，模拟20张的首帧为146.3ms（单次），快门至可靠暂存中位64.4ms/p95 70.3ms，水印处理中位83.4ms/p95 98.2ms，单次本地写入中位1.9ms。10张和20张均未观测到超过50ms的主线程长任务。此前与单元测试并行的回归20张观测到5次长任务、快门暂存p95 284.1ms，完整保留于记录，说明CPU负载仍影响体感，不能保证低性能实机绝不卡顿。分享接口桩仅验证手势与流程，不提供真实系统面板出现耗时。

## 验证与上线边界

- 单元测试227项；手机浏览器回归24项。覆盖10/20连拍、原尺寸输出、取消/刷新恢复、无文件分享API、单张能力、多文件拒绝、各类分享异常、分享不返回、处理进度、离线ZIP实际下载及独立ZIP解包CRC验证、无Worker兼容路径，以及原事项采购流程。
- Service Worker构建缓存版本更新到v13模板，由构建内容哈希生成最终名称。更新只清理旧CacheStorage，测试确认旧照片库与新临时批次IndexedDB均不被删除。
- 类型检查、生产前端/API构建、部署工具构建及格式检查通过。没有新增依赖、业务数据库迁移、付费服务、云端照片库或生产部署；已有照片和未同步业务数据保留。
- 华为/vivo实机分享面板、下载管理器、系统相册写入、真实硬件快门耗时与持续连拍内存表现：**未验证**。请更新后分别测试一次多张保存、ZIP下载并解压、单张保存及取消后重试；未确认导出前不要清理站点数据或卸载PWA。
