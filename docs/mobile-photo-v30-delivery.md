# 手机拍照 V3.0：全屏连续拍照与批量保存

## 实际交付

点击拍照 → 真实GPS及附近地点选择 → 确认 → 直接进入网页后置相机 → 连续按快门 → 完成拍摄直接调用多文件系统分享 → 用户在系统界面选择存储图像 → 明确确认后清理对应副本并返回管理页。

默认流程不再进入系统文件相机，不显示V2的相机模式菜单。摄像头权限失败时才在恢复页保留重试/系统相机兼容入口，不能用兼容入口宣称拥有网页连续取景能力。

相机通过Portal直接挂载body，position:fixed及100dvh覆盖可用屏幕，不使用iOS视频全屏接口（否则HTML水印无法跟随）。隐藏原顶部、底部菜单；使用safe-area-inset适配安全区。顶部关闭及地点，中间真实后置视频/半透明品牌水印，底部张数、圆形快门、完成。视频object-fit:cover仅裁切预览；正式照片使用ImageCapture静态输出，或浏览器不支持时使用视频实际像素完整画面，不应用预览裁切。

水印按秒更新时间，最终按捕获时间合成到图片像素；原始Logo保持比例。工地定位不额外添加“附近”。GPS、精度、时间、人工/POI来源及捕获方式保存在暂存元数据与输出JPEG XMP中，不宣称人工地址已经被GPS精准验证。真实相册再导出是否保留XMP仍需真机核验。

## 连拍及内存控制

- 会话内保留同一摄像头，逐张拍摄不打开分享或返回地址；新照片不上传云端照片库。
- 原始捕获先写入原有临时批次库，后台复用水印Worker/兼容处理器；可靠写入水印图后替换临时原始捕获。处理失败保留原始捕获，写入失败保留内存副本并提供恢复入口。
- UI列表只保留元数据与字节计数，不持有整批原始图/水印ArrayBuffer。恢复时按当前账号键前缀游标读取摘要，按需读取单张。
- 最多同时容纳两项正常图像处理任务，快门临界时排队等待空位，不将正常后台写入误判成存储失败，也不静默忽略已接受的点击。总照片张数不设10/20等固定限制。
- 系统可用空间不足时暂停新拍摄并提示先保存。浏览器强退或系统回收仍可能丢失尚未可靠落盘的内存文件，不能作绝对不丢图承诺。
- 预先构造可分享File，导出缓存预算64MiB；大批次其余照片留在IndexedDB，使用明确告知的分批导出。用户确认清理某批后才加载后续照片，不一次性把任意大批次全部装入内存。
- 页签隐藏时暂停快门，重新可见后等待新视频帧；媒体轨道中断时禁用快门并提示重新进入，避免捕获旧画面。权限请求未完成时关闭，晚返回的媒体流立即停止，不重新打开相机。

## 完成与保存真实性

完成按钮仅在全部当前照片已生成水印并可靠保存后启用。点击事件中直接使用预构建File调用navigator.canShare/navigator.share，没有在点击后先await图像处理或IndexedDB读取而丢失用户激活。

分享Promise成功只显示“已交给系统分享”，不宣称系统相册已保存。用户取消仍保留所有副本，可以重试。正常恢复页以张数及保存/确认按钮为主，分批和逐张导出折叠在“更多保存方式”，失败时自动展开。不提供常驻照片管理列表。

平台不支持大批文件、文件过多或内存预算不足时分批（兼容按钮最多5张），或在页内显示单张图片长按导出。不进行顶层blob:导航，不提供ZIP，也不把ZIP、浏览器暂存或系统分享打开当作相册保存成功。

用户明确确认已在系统相册看到照片后，才删除已分享/导出的具体暂存ID。取消分享、关闭相机、返回管理、刷新都不清理唯一文件；同账号再进入拍照可恢复未导出内容。

## 数据与范围

复用现有GPS/2公里高德POI/分页/搜索/手动命名/地点签名。无新付费服务、原生App、云端照片库或服务器数据库迁移。

沿用chunmo-photo-batches格式读取V2待导出照片，不升级或清空数据库。旧chunmo-site-photos、云端私有照片目录、项目关联及待同步资料不变。电脑业务布局及保存逻辑未改动；MobileAssistant只调整相机活动时的导航可见性及新相机入口。

## 性能与像素：模拟环境，不能替代iPhone实机

测试环境为Linux Chromium、模拟后置摄像头/GPS/高德响应与Web Share桩。真实iPhone Safari、安装后的PWA、真实授权弹窗、系统“存储N张图像”及相册结果均未实机验证。

采集每项指标的原始统计见[性能记录](mobile-photo-v30-performance.json)。相机首帧/初始化每轮为单次观测，其余为该轮每张的中位数；快门间隔另包含Playwright输入及等待开销，不代表硬件连拍极限。

| 指标                   | 10张模拟 | 20张模拟 |
| ---------------------- | -------- | -------- |
| 确认地址至首帧         | 175.4ms  | 138.6ms  |
| 相机初始化             | 53.6ms   | 32.8ms   |
| 快门至原始捕获可靠暂存 | 76.1ms   | 78.5ms   |
| 水印渲染               | 89.4ms   | 91.6ms   |
