# 拍照地图地点限制、连拍优化及品牌水印

## 地点策略

取消当前拍照地址弹层的手动名称输入和兜底。名称搜索仍只查询高德返回的2公里内POI；默认最近、分页、更换地点保留。无合格地点/接口不可用时只能重试，不能自行填写名称继续拍摄。

服务端不再签发新的手动地点凭据，也不允许通过续期接口改名。原签名必须来自高德POI，续期会将最新WGS84 GPS转换为GCJ02，与已签名POI坐标重新计算距离；超过2公里拒绝续期，前端阻止新拍摄。GPS精度、取得时间、所选POI及来源仍保留。范围是依据设备GPS计算，候选不是人在该建筑内的独立证明，也不构成防GPS伪造认证。

历史手动照片和未导出文件不删除、不改来源、不重分类；历史已捕获的有效签名仍可按原拍摄时刻校验，用于恢复旧文件。新增手动签名和人工来源续期均被拒绝，旧资料兼容不作为新拍摄手动入口。

## 卡顿优化

- 地址选择期间提前初始化水印Worker并加载Logo，避免第一次快门才冷启动；前台相机会话内保持Worker，退出后空闲释放，执行中的水印任务不会被空闲回收中断。
- 位置信息有效期内复用已确认的地图地点，前台会话后台更新GPS/签名，合并并发更新请求；不再因为超过30秒就让每次快门串行等待GPS。后台页面不主动刷新GPS；凭据过期或地图半径失效仍阻止新拍摄。
- 存储容量检查在开机时并行预取、短时缓存，移除每张快门的重复查询；最终IndexedDB写入仍是可靠保存依据。
- 连拍复用全像素捕获Canvas及ImageCapture对象，避免每帧反复分配/释放大型Canvas。没有缩小照片、裁切输出或降低原有JPEG质量。
- 新流程不再生成未使用的缩略图；JPEG来源元数据在水印Worker内附加，减少主线程的大图字节复制。兼容路径保持相同水印及来源数据，旧照片模块仍默认生成其需要的缩略图。
- 保留原来的处理背压、暂存失败保图、64MiB分享缓存预算和确认后精确清理机制。

## 水印

源Logo文件不变，在Worker圆形裁切及SVG圆形clipPath中绘制，预览也使用圆形裁切；不重绘、不拉伸。预览Logo由28px调至36px；导出Logo由34个布局单位调至44。公司名称使用32个布局单位字号，明细文字仍为24（预览公司名为明细的约1.33倍）。

预览、Worker导出及SVG兼容导出的深色底板统一为55%不透明度，较原导出78%更透明。固定地点、时间、姓名信息及实际像素输出保留。

## 验证

- 224项单元测试通过，覆盖地图来源、半径、圆形品牌和透明度，以及原业务和照片队列。
- 4项照片API测试通过，包括禁止手动签发/续期/改名、续期移出2公里拒绝、账号隔离，以及历史手动照片恢复不受影响。
- 14项手机浏览器回归通过，包括无结果没有手动入口且不能拍摄、后台GPS移出范围禁用快门、10/20连拍、4000×3000静态输出、3840×2160视频帧兼容输出、真实像素水印、批量分享/取消恢复、空间不足保图、旧照片不变及原事项采购功能。
- 最终12MP水印用例另复测通过；生产构建、部署工具构建、格式及diff检查通过。

模拟环境为Linux Chromium、模拟相机/GPS/POI和Web Share桩，未访问真实高德Key进行场地覆盖验收，未进行iPhone Safari或安装后PWA真机流畅度/相册验证。完整指标见[性能记录](mobile-photo-v31-performance.json)。相机启动每轮仅单次观测，不能当作稳定设备统计：
